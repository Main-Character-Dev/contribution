# Contribution contracts

[Schemas](schemas/README.md) are canonical draft 2020-12 inputs with unchanged v1 URNs. [Examples](examples/README.md) are synthetic, independent scenarios. All twelve schemas are compiled into a local Ajv 8.17.1 registry with ajv-formats 3.0.1. Validation never fetches a schema over the network. Unknown URNs fail resolution; unknown schema names fail explicitly. UUID, date-time and URI format checking is enabled. The reviewed schemas currently use UUID/date-time; a separate formatter proof exercises URI as well.

`scripts/generate.mjs` uses json-schema-to-typescript 15.0.4 to generate all twelve TypeScript projections. Its resolver rewrites local URNs only in memory and disables HTTP. `unknown` preserves additive payload uncertainty without `any`. Generated types provide structural assistance; they cannot express all `if`/`then`, `contains`, format, minimum, pattern, or cross-record rules. Compilation is never permission to bypass Ajv. The runtime registry enforces the full schemas, and engine response constructors validate before returning. Strict validator keyword checks fail on unsupported constructs. Do not weaken canonical JSON to accommodate static types.

The Swift `ResponseEnvelope` is a small checked Codable projection of response v1 plus the version result slice. Status/state enums are generated from the canonical response schema. Decoding requires all six envelope fields including explicit nulls, validates enums, nonempty identifiers, error/action shape, and all three response conditionals. `JSONValue` retains unknown envelope/error/action/result keys, nested arrays and explicit nulls during re-encoding. Numeric payloads use Foundation Decimal; values outside its supported range are not a qualified transport contract. No Swift projection or fixture claims to validate repository/device schemas or cross-record authority. The engine remains the runtime validation authority for those schemas and all product payloads.

`native:test` prepares the same nine positive and eleven negative envelope cases checked by Ajv, then exercises Swift decode/round-trip rejection and compares both development responses with the engine. Future transport implementation must bound frames, validate canonical payloads at admission, and explicitly reject incompatible schema versions; S0 does not create IPC.

`version.json` supplies the application/interface/engine development identity through generated TypeScript, Swift and Xcode configuration. Static generated files are checked in; `check:generated` rejects drift. The private packages have no independent release versions.

Run the commands in [BUILD.md](../../docs/BUILD.md). Import hashes remain in [source-imports.json](../../docs/source-imports.json). No schema or example JSON remains under `docs`.
