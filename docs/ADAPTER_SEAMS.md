# Adopted project seams

The four policy families retain their original runtime pins, integration ownership, validation, attribution and dispatcher behavior. Current adapters inspect and bind actual source fingerprints; dated runtime observations in [seam history](IMPLEMENTATION_HISTORY.md#adopted-project-seam-history) are not runtime constants. No live project has been enrolled or cut over.

| Shared seam | Current implementation / proof | Remaining boundary |
|---|---|---|
| Primary mutation lease | Compatible original owner protocol; [four-source parity](verification/legacy-lease-parity.json) | Unknown locks remain protected |
| Landing flights | Compatible exact joins, conflicts and FIFO; [parity](verification/legacy-flight-parity.json) | A join does not prove original validation |
| Hook borrowing | Actual Git ancestry, exact invocation and outer lease; [bridge parity](verification/legacy-bridge-parity.json) | No arbitrary caller or token substitutes for ancestry |
| Original publication | Original gate/runtime/arguments/stdin, retained completion and actual destination readback | Live full-gate parity and publication remain deferred; Glass Alpha stays inactive |
| Reporting | Private per-attempt sealed evidence and immutable review proposals | Proposed patches preserve original default paths and policy |
| Reversible adoption | Reviewed apply, committed migration range, explicit activation and rollback; [flow](ADOPTION.md) | Preserve concurrent edits and original receipts; no automatic live migration |
| Original landing | [Captured/native task route](ADOPTED_LANDING.md), source ownership and resume of independent follow-up | Full adopted cross-host import and writer cutover remain incomplete |
| Project runtime | `repos runtime --repo ID --node /absolute/node --pnpm /absolute/pnpm` revalidates exact source pins | Bundled runtime never silently replaces project tools |

`repos migration --repo ID [--adapter ID]` inventories current seams. Unknown or changed source fails closed; generic selection cannot bypass an existing policy owner. Reporting proposals (`--prepare-reporting --request-id UUID`) do not apply or activate them. Standard configuration cannot forge adoption. Configuration changes to an active adopted project reverify original fingerprints and bind unchanged registration to the new revision; old rollback snapshots do not overwrite later owner edits.

Mathy retains policy-only landing and its own preparation lease; Main Character and Roboty retain integration-only landing and cumulative publication gates; Glass Alpha retains one-date attribution and visibly inactive validation. Read the current primary policy at enrollment. The [history](IMPLEMENTATION_HISTORY.md#adopted-project-seam-history) and dated parity receipts distinguish synthetic patch compatibility, disposable source execution and unrun live migration.
